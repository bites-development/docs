# BOOX

BOOX is the customer-facing product family built on Bites. It combines shared
identity, workspace controls, catalog and invoice foundations with focused
experiences for commerce, service businesses, rentals, and in-store operations.

## Workspace isolation

BOOX uses the same active-workspace boundary as Bites. A user sees only the
records, sites, and integrations permitted in the selected workspace. Switching
workspaces changes the active business context; it does not merge their data.
